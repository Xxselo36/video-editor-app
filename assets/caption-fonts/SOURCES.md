- Upstream: [google/fonts](https://github.com/google/fonts) at commit `23e54b51ddffbc7713c583748e3bd86f62b1fa4a`
  (files under `https://raw.githubusercontent.com/google/fonts/<commit>/<path>`).
- Variable fonts are instantiated to the static weight with fontTools 4.66.0 (`varLib.instancer`, `updateFontNames=True`); static upstream files are copied byte for byte.
- The web subsets in `web/public/fonts/captions/` and the metric tables in `web/src/lib/captions/fonts.json` are generated from these TTFs by the same script.
- Each family's upstream project and commit are in `METADATA.pb` next to the source file at that commit.
- CJK fallbacks (Noto Sans JP/KR/SC ExtraBold) are not stored here: they are subset per job (UT3).
